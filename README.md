## 🎯 СУПРА — Система Управления Приоритетами РАбот (2025 → now)

Расширение для 1С:БСП (платформа 8.3.26+), которое планирует задачи в реальном времени: даты старта и окончания пересчитываются по графу зависимостей асинхронно, без блокировок интерфейса и карточек задач.

**Для кого:** ИТ-команды, проектные офисы и внедренцы на 1С, которым нужен быстрый и простой инструмент планирования.

- **Режим реального времени.** Инкрементальный пересчёт дат по графу зависимостей без нажатия кнопок. Исполнители работают как обычно: меняют статусы, трудоёмкость, атрибуты, вносят отчёты о работах.
- **Два режима загрузки ресурсов:** одна задача на исполнителя в единицу времени либо без этого ограничения.
- **Гибкая методология.** Бэклог, спринты, настраиваемая доска задач в духе Jira/Agile.
- **Приоритет = позиция в списке.** Подход, который в MS Project реализуется настройкой «Leveling order = ID ONLY» ([пояснение](https://gaperton.livejournal.com/19205.html)).
